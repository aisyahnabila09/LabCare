LABCARE WEBSITE — PETUNJUK SINGKAT

File:
- index.html                 : halaman beranda
- tampilan-aplikasi.html     : katalog perangkat, pencarian, filter, detail
- lapor-kerusakan.html       : form laporan + riwayat demo
- presentasi-kontak.html     : anggota tim + form masukan
- peluang-pengembangan.html : manfaat dan rencana pengembangan
- style.css                  : semua desain dan responsivitas
- script.js                  : interaksi JavaScript

Cara menjalankan:
1. Ekstrak folder LabCare-Website.
2. Buka folder di VS Code.
3. Jalankan index.html memakai ekstensi Live Server (disarankan), atau buka file index.html di browser.
4. Navigasi antarhalaman menggunakan menu di bagian atas.

Catatan:
- Data komputer adalah data contoh.
- Form laporan dan masukan tersimpan di localStorage browser, bukan dikirim ke server.
- Untuk sistem sungguhan, perlu backend dan database.
